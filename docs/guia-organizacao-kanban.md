## 📱 **DICAS DE USO DO KANBAN**

### **Durante Execução**:
1. **Começar task** → Mover para "In Progress"
2. **Completar task** → Mover para "Done"
3. **Atualizar checklists** dentro da issue (☑️ critérios de aceite)
4. **Seguir dependências** (não começar #27 sem #26 completo)

### **Acompanhar Progresso**:
- **Done**: Issues completadas  
- **In Progress**: Issue atual sendo executada
- **Todo**: Próximas issues na fila
- **Backlog**: Issues futuras

### **Filtragem por Labels**:
- `epic:low-code` → Ver apenas tasks Low-Code
- `priority:critical` → Ver apenas tasks críticas
- `type:backend` → Ver apenas tasks de backend
